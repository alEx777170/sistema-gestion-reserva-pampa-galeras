TECNOLOGÍAS
-----------
- Frontend: React 18 + Vite + React Router + Axios
- Backend: Node.js 20 + Express + node-oracledb (modo thin)
- Base de datos: Oracle Autonomous Database 26ai (Always Free, OCI)
- Empaquetado: Docker (imagen multi-etapa: Vite + Express) + docker-compose
- Servidor: Render.com (plan Free, servicio web construido desde Dockerfile)
- Despliegue de BD: script automático backend/setup_adb.js (adaptado a ADB)


DESPLIEGUE (resumen)
--------------------
1. El esquema se cargó en la ADB con:  cd backend && node setup_adb.js
2. El sistema está desplegado en Render desde el Dockerfile de la raíz;
   la conexión a la ADB usa el wallet inyectado como variable WALLET_B64.
3. Detalle completo: ver DESPLIEGUE.md en la raíz del proyecto.
